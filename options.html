Peekaboo is ready

Open a GitHub pull request with Before and After screenshots. They're already stacked and flipping.

Auto-align screenshots of different sizes

When the Before and After were captured at different window widths, or one is a crop of the other, Peekaboo can find where they line up and show only what really changed. It also says how much of each pair changed, warns when Before and After are the same picture, and lets full screen zoom to each change.

For that it reads the two images from GitHub's image server. Nothing else is read, nothing is sent anywhere, and Chrome asks you once.

Off

How to use it

Flip is the default: click the picture or press Space to swap Before and After. Diff lights up only the pixels that changed: red was there before, green is new. Full screen steps through every pair with ← →, and with Auto-align on, ↑ ↓ zoom to each place that changed.

Tables it picks up

Any table in a PR or issue whose columns start with Before and After, with a screenshot in each cell. Extra columns become labels; an italic line under the table becomes the caption.

| Before | After |
| --- | --- |
| ![Before](before.png) | ![After](after.png) |
